---
description: "Стилевые инварианты при создании и правке .bsl-файлов (авто-напоминание)"
condition: "**/*.bsl"
interruptMode: never
---

Стиль 1С/BSL (полные правила: `rule://1c-bsl-code-style`):

- после создания или правки прогнать
  `python3 .omp/rules/1c-bsl-code-style/scripts/bsl_style_check.py <path>`
  (с `--fix` при праве на запись), после fix — повторно;
- не менять поведение под видом стиля: защитные условия, fallback-ветки,
  момент создания объектов, источник даты, вызываемый API;
- табы на пустых строках внутри методов — не trailing whitespace, не удалять;
- операторы только `Не`, `И`, `Или`; пустой конструктор без скобок; пробел
  после запятой;
- вложенность `Если...Тогда` не глубже двух уровней;
- без массового переформатирования, если задача не была форматированием;
- query text: `Запрос.Текст = "` + `|` строки + `|";` на своей строке;
- WHERE 2+ условий: первое условие `ИСТИНА` (только для первой ГДЕ, не UNION-веток);
- булевы выражения: `(Ложь Или ...)` / `(Истина И ...)` в колонку;
- тернарный >140 символов: многострочный;
- вызов 3+ аргументов: по одному на строку;
- описания типов входных/выходных параметров (`Параметры:` /
  `Возвращаемое значение:`) — обязательны у любого метода, который получает
  параметры или возвращает значение, не только у экспортных; служебному
  методу аннотация не нужна, если всё очевидно из названия;
- все многострочные конструкции закрываются закрывающей скобкой на отдельной
  строке, т.е. не `ОписаниеОшибки);` в конце последнего аргумента, а
  `ОписаниеОшибки` + `);` на своей строке; даже если статанализ ругается
  на такой стиль — это правило имеет высший приоритет;
- «умная типографика» в .bsl запрещена: тире (— –), многоточие (…),
  неразрывный пробел, знак минус (U+2212), soft hyphen — только ASCII-аналоги
  ("-", "..."); bsl-analyzer ругается на них InvalidCharacterInFile
  (проверка guard: `invalid-char`);
- без цепочек вызовов: `Запрос.Выполнить().Выбрать()`,
  `Загрузить(…Выгрузить())`, `Скопировать(…).Количество()` — каждый шаг
  отдельной строкой с именованной промежуточной переменной (guard:
  `chained-call`; исключения: `ПустаяСсылка()`, преобразующие функции
  `Строка/Число/НачалоДня/…`, fluent `ЮТест`);
- вызов или конструктор аргументом другого вызова — в именованную переменную
  (`Метод(Арг, ДругойМетод(...))`, `Колонки.Добавить("X", Новый ОписаниеТипов(...))`;
  guard: `nested-call-arg`);
- пропущенных аргументов нет: `ПоказатьПредупреждение(Неопределено, …)`,
  а не `ПоказатьПредупреждение(, …)` (guard: `omitted-arg`);
- одинаковый `Новый ОписаниеТипов(...)` не повторяется в методе inline —
  именованная переменная или helper-схема колонок (guard: `named-type-desc`).

# Каталог features — сценарные тесты (Vanessa Automation)

Gherkin-сценарии (`*.feature`) для проверки функциональности через Vanessa Automation.

## Правила
- Файлы фич: `#language: ru`, теги, структура `Функционал → Сценарий`.
- Сценарии пишутся от лица пользователя: `Как / Я хочу / Чтобы`.
- Запуск — через vrunner (vanessa), параметры — в `tools/VAParams.json`.

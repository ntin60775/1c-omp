# Каталог src/cf — исходники конфигурации

XML-выгрузка конфигурации (Designer). Источник правды для сборки конфигурации.

## Правила
- Не редактируй XML вручную без необходимости — изменения вносятся в конфигурацию, затем выгружаются.
- Служебные файлы выгрузки (`ConfigDumpInfo.xml`, `lastUploadedCommit.txt`) не коммитятся — см. `.gitignore`.

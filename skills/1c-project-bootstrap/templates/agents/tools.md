# Каталог tools — инструменты и конфигурации

Конфигурации инструментов разработки и тестирования (JSON), вспомогательные утилиты.

## Правила
- `VAParams.json` — параметры Vanessa Automation, `yaxunit.json` — параметры YAxUnit, `syntax-check-excludes.txt` — исключения синтаксического контроля.
- Секреты и пароли сюда не класть.

# {project_name}

Новый проект 1С. Этот файл — входная точка для агентов: начни с него.

## Структура проекта

| Каталог | Назначение |
|---|---|
| `docs/` | Документация проекта (Markdown) |
| `features/` | Сценарные тесты Vanessa Automation (Gherkin, `*.feature`) |
| `fixtures/` | Тестовые данные и макеты для автотестов |
| `src/cf/` | Исходники конфигурации (XML-выгрузка) |
| `src/cfe/` | Исходники расширений |
| `src/epf/` | Исходники внешних обработок |
| `src/erf/` | Исходники внешних отчётов |
| `tasks/` | Скрипты и задачи OScript (сборка, автоматизация) |
| `tests/cfe/` | Исходники тестовых расширений (YAxUnit) |
| `tests/epf/` | Исходники тестовых обработок |
| `tools/` | Конфигурации инструментов (vrunner, Vanessa, YAxUnit) |

## Правила для агентов

- Не клади файлы в каталоги, не соответствующие их назначению.
- Существующие файлы не перезаписывай без явного запроса.
- Служебные артефакты сборки (`build/`, `oscript_modules/`) в git не попадают — см. `.gitignore`.
